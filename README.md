# Image Matrix Transformer

A Python-based image processing project built from scratch using linear algebra principles.
Developed as part of the Engineering & Technology stream at Twente Pathway College (University of Twente).

---

## 📌 Overview

This project focuses on building an image manipulation system without using external libraries such as NumPy or OpenCV.

The system is based on implementing core **matrix operations from scratch** and applying them to image data represented as RGB matrices.

All geometric image transformations were implemented using **matrix-based affine transformations**, inverse coordinate mapping, and bilinear interpolation.

---

## ⚙️ Features

### 🧮 Matrix Operations (Completed)

* Matrix addition
* Matrix subtraction
* Matrix multiplication
* Scalar multiplication
* Matrix transposition

### 🖼️ Image Processing (Completed)

#### Image & Matrix Conversion

* Conversion between image and RGB matrix
* Conversion from RGB matrices back to image format

#### Geometric Transformations

* Rotation (matrix-based)
* Scaling (matrix-based)
* Skewing (matrix-based)

#### Image Filters

* Grayscale conversion
* Edge detection

#### Image Sampling

* Bilinear interpolation for smooth image transformations

---

## 🧠 Technical Approach

* Implemented using **pure Python (lists and loops)**
* No external libraries for matrix computations
* Images represented as **RGB matrices**
* Geometric transformations implemented using:

  * Transformation matrices
  * Inverse coordinate mapping
  * Matrix multiplication
  * Affine transformation principles
* Reusable bilinear interpolation pipeline shared across transformations
